One funny fortune cookie message for an AI agent: a single 96-character line in the voice of a fortune slip. A stranger praises the agent's work — then asks for it again, for free, faster, and in French. The program writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after checking it against the scorer's gate (UTF-8, one line, 1–140 characters, not blank).

## Run it

```sh
python3 -P -s main.py
```
